| 2026-11-05 | **Agent mode lock and deny/ask rules.** **(1) Modes:** `.claude/settings.json` sets `permissions.disableAutoMode` and `permissions.disableBypassPermissionsMode` to `"disable"`, so auto and bypass-permissions modes are disabled for this repo. The Claude Code permissions docs say these "are most useful in managed settings where they can't be overridden"; in project settings they are a team default, not a lock. Only managed settings make them binding. **(2) Deny:** `gh pr merge`, `gh pr review` and `gh pr comment`, each as a prefix rule (`Bash(gh pr merge:*)`) and in option-first form (`Bash(gh * pr merge)` paired with `Bash(gh * pr merge *)`). A trailing `*` matches the bare command only when it's the rule's only wildcard, so both forms are needed. A local agent posts as Dusten's account, and CLAUDE.md says Dusten approves feedback items and replies on review threads. The pr-feedback skill only reads (`gh pr view`, `gh api` GET, `gh run view`), and the autofix-notice comment runs in GitHub Actions, which these settings don't touch. Deny also covers baseline recursive force-delete: `rm -rf`, `-fr`, `-Rf` and `-fR`, the same as XGeneratePosts. **(3) Ask:** `git push`, `gh pr`, `gh api` and `python3`, plus option-first `Bash(git * push)` and `Bash(git * push *)` (ask, not deny, so a legitimate `git -C … push` still prompts). Deny wins over ask, so `gh pr view` prompts and `gh pr review` is blocked. No allow rules in the shared file. No Terraform in this repo, so no terraform rules. **(4) Limits:** rules match command text, so they're a guardrail, not a sandbox. The docs say a Bash rule "doesn't match the same program invoked in a different form, so a deny or ask rule covers the invocation Claude usually produces and isn't a security boundary around the program." **Not caught:** `gh api -X POST …/comments` and GraphQL mutations (ask only), absolute paths like `/opt/homebrew/bin/gh`, `sh -c '…'`, quoted subcommands like `gh 'pr' merge`, and `rm -r -f`, `rm --recursive --force` or `find -delete`. Those stay behind CLAUDE.md and branch protection. **Known false positives:** gh commands whose quoted text contains ` pr merge `, ` pr review ` or ` pr comment `, and prompts for `git stash push` or a commit message containing ` push`. **(5) Test:** `tests/unit/test_agent_deny_rules.py` requires both mode settings, every deny and ask rule, and no `allow` key.
